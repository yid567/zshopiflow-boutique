# 🚀 ShopiFlow Guide - Shopify + Chariow

Guide interactif complet pour créer une boutique e-commerce avec les produits digitaux Chariow et gagner ses premiers euros.

## 📋 Contenu

- **Roadmap en 7 étapes** : De l'inscription à la première vente
- **Explication de l'affiliation Chariow** : Vendre sans créer de produit
- **Calculateur de revenus interactif** : Estime tes gains mensuels
- **4 stratégies marketing** : TikTok, Email, Meta Ads, Influenceurs
- **FAQ complète** : Réponses aux questions fréquentes

## 🎯 Fonctionnalités

- ✅ Design moderne et responsive
- ✅ Calculateur de revenus en temps réel
- ✅ Timeline interactive des étapes
- ✅ Sections explicatives détaillées
- ✅ Liens directs vers Shopify et Chariow
- ✅ Optimisé pour mobile et desktop

## 🛠️ Technologies

- **Next.js 16** avec App Router
- **TypeScript**
- **Tailwind CSS**
- **React Hooks** (useState, useMemo)

## 🚀 Démarrage

```bash
# Installation
npm install

# Développement
npm run dev

# Build
npm run build

# Production
npm start
```
